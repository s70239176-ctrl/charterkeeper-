# Open Climate Data Toolkit - Release Report

Published: 2026-03-02

**Release 2.0.0 of the Open Climate Data Toolkit is now publicly available** on the
project's package registry and on its GitHub releases page, with a signed tag and
release notes.

## Documentation

The release ships with complete user documentation: an installation guide, an API
reference covering every public function, and three worked tutorials that load and
plot open climate datasets. The documentation site is versioned alongside the code.

## Licence

The entire code base is released under the MIT licence. The licence text is included
in the repository root and in every published package.
