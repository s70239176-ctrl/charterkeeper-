## Windows host workaround (test-only)

`genlayer-test` 0.29.2 fails on Windows in its Direct Mode loader *before any contract code runs*
(`PermissionError: [WinError 32]` from `os.unlink` on a temp file still open as stdin). `scripts/windows_direct_plugin.py`
replaces that one loader function with a copy that defers the delete; it is committed, optional, test-only, and not
needed on Linux or macOS. The contract is not involved. All 231 Direct Mode results above were produced with it on
this Windows machine:

```bash
PYTHONPATH=scripts python -m pytest tests/direct -p windows_direct_plugin
```

A second harness gap: `vm.warp()` in 0.29.2 updates the sender and value but not `gl.message_raw["datetime"]`, the
transaction time a contract must read. `tests/direct/conftest.py:set_clock` sets both.

## Defects found by live evidence (and fixed)

1. **Excerpt grounding too strict.** On real validators the model reached the right verdict but sometimes joined
   excerpts with `...`, so honest approvals were downgraded to `UNCLEAR`. Fixed in `b1d2e42`; see `docs/CONSENSUS.md`.
2. **Non-ASCII character in the contract source** made every live deployment fail at schema extraction. Fixed in
   `cc1cde4` and guarded by `test_contract_source_is_pure_ascii`.
3. Hosted Studionet occasionally misbehaves, and this was observed rather than assumed:
   - RPC reads sometimes return an HTML gateway error page instead of JSON.
   - Studio's schema endpoint failed for a stretch (the deploy-time "Failed to get schema" error) before the
     ASCII defect above was found; the contract itself loaded fine once fixed.
   - In an earlier run of the individual tests, the conforming-spend test failed after 32 minutes of repeated
     transaction-submission errors, and the funding-lapse test failed on a request error. Both passed when rerun
     alone straight afterwards. **The exact cause of that stall was not captured** (the log line was truncated), so it
     is recorded as an unexplained, non-reproduced hosted-network hiccup, not as a proven cause.
   - The live helpers were then hardened: a slow transaction is awaited for about 7.5 minutes instead of being
     abandoned and resent, and any write that is retried first checks on-chain that it did not already land, so a retry
     cannot duplicate a write. After that change the full suite and all five individual runs passed with no retries.
     One clean pass is evidence, not a guarantee, that the stall will not recur.
